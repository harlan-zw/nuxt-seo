## Update Command

Since `@nuxtjs/seo` bundles all nine modules, you only need to update the main package. If you pinned a module in your `package.json`, update that pin too. An older pinned module fails the build.

::code-group

```bash [pnpm]
pnpm update @nuxtjs/seo --latest
```

```bash [npm]
npm update @nuxtjs/seo@latest
```

```bash [yarn]
yarn upgrade @nuxtjs/seo --latest
```

```bash [bun]
bun update @nuxtjs/seo --latest
```

::

## When Updates Get Stuck

Package managers can cache old versions. If updates aren't applying:

::code-group

```bash [pnpm]
rm -rf node_modules pnpm-lock.yaml && pnpm install
```

```bash [npm]
rm -rf node_modules package-lock.json && npm install
```

```bash [yarn]
rm -rf node_modules yarn.lock && yarn install
```

```bash [bun]
rm -rf node_modules bun.lockb && bun install
```

::

## Check for Breaking Changes

Before updating major versions, follow the [migration guide](/docs/nuxt-seo/migration-guide/v5-to-v6) and check the [GitHub Releases](https://github.com/harlan-zw/nuxt-seo/releases).

Individual module changelogs:

- [Sitemap](https://github.com/nuxt-modules/sitemap/releases)
- [Robots](https://github.com/nuxt-modules/robots/releases)
- [OG Image](https://github.com/nuxt-modules/og-image/releases)
- [Schema.org](https://github.com/harlan-zw/nuxt-schema-org/releases)
- [Link Checker](https://github.com/harlan-zw/nuxt-link-checker/releases)
- [SEO Utils](https://github.com/harlan-zw/nuxt-seo-utils/releases)
- [Site Config](https://github.com/harlan-zw/nuxt-site-config/releases)
- [AI Ready](https://github.com/harlan-zw/nuxt-ai-ready/releases)
- [Skew Protection](https://github.com/harlan-zw/nuxt-skew-protection/releases)

## Verify the Update

After updating, check your installed version:

```bash
npx nuxt info
```

Look for `@nuxtjs/seo` in the modules list.
