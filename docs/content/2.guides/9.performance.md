Disable modules you do not use. Prerender outputs that can stay the same until your next deploy. Keep runtime generation for output that needs fresh data.

| If your site… | Use | Check before you deploy |
| --- | --- | --- |
| Manages its own social images | `ogImage: false` | Your pages still emit `og:image` and those URLs load. |
| Can generate every social image at build time | `ogImage.zeroRuntime: true` | Prerender every page that uses `defineOgImage()`. |
| Has sitemap URLs that change only when you deploy | `sitemap.zeroRuntime: true` | The XML lists the expected URLs, languages, and child sitemaps. |
| Can serve page Markdown from files built at deploy time | `aiReady.zeroRuntimeMarkdown: true` | Your AI Ready version supports this option. |
| Has no need for a module's output | Set its config key to `false`. | You have another source for any routes or tags you still need. |

## Use prebuilt output

Choose the options that fit your site. Before adding `aiReady.zeroRuntimeMarkdown`, check that your installed AI Ready release includes it. [AI Ready releases](https://github.com/harlan-zw/nuxt-ai-ready/releases)

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxtjs/seo'],
  sitemap: { zeroRuntime: true },
  ogImage: { zeroRuntime: true },
  aiReady: { zeroRuntimeMarkdown: true },
  nitro: {
    prerender: {
      routes: ['/', '/about'],
    },
  },
})
```

Replace the example route list with your own. List pages explicitly if the prerender crawler cannot reach them.

- **Sitemap.** A zero runtime sitemap changes only when you deploy. Keep runtime generation if URLs can appear or change between deployments. [Sitemap Zero Runtime](/docs/sitemap/guides/zero-runtime)
- **OG Image.** Prerender every page that needs a generated social image. Keep runtime generation for pages that create images on demand. [OG Image Zero Runtime](/docs/og-image/guides/zero-runtime)
- **AI Ready.** Prerender every page that needs Markdown. Pages without a prebuilt Markdown file serve HTML. A direct request for a missing page `.md` URL returns 404. Runtime Sync and cron can still include the converter. [Prerendered-only Markdown](/docs/ai-ready/guides/markdown#prerendered-only-markdown)

## Keep prerendered pages on the static host

On Cloudflare Workers, AI Ready leaves your asset routing as configured by default. Clients can request the prebuilt `.md` files directly.

Set `aiReady.contentNegotiation: true` to negotiate Markdown for your prerendered pages. AI Ready adds those paths to Worker-first routing where your configuration allows it. Matching HTML requests also go through the Worker. Measure those routes before enabling it. [Markdown negotiation on Cloudflare](/docs/ai-ready/guides/markdown#runtime)

## Measure the build you plan to deploy

Compare two production builds with the same Nuxt version, routes and deployment preset. Change one option per comparison.

1. Compare the compressed server upload and initial client entry. Cloudflare's deployment output reports upload size and Worker startup time.
2. Time the first request to the same server-rendered page on a fresh instance. Repeat with several fresh instances per build. Measure repeat requests separately.
3. Request a prerendered page, a live SSR page, `/robots.txt`, your sitemap and one social image. If you use AI Ready, also check a prebuilt Markdown URL and `/llms.txt`.

Keep the options that improve your measurements and preserve the output your site needs.
