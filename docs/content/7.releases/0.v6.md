## Introduction

Nuxt SEO v6 adds AI Ready and Skew Protection to the bundle and updates all nine modules.
It requires Nuxt 4.6.1 or Nuxt 5. Nuxt 3 projects stay on v5.
For upgrade steps, see the [v5 to v6 migration guide](/docs/nuxt-seo/migration-guide/v5-to-v6).

::ui-button{to="#upgrading" purpose="secondary" size="sm"}
Skip to upgrade
::

## 🤖 AI Ready and Skew Protection, Bundled

[AI Ready](/docs/ai-ready/getting-started/introduction) generates `llms.txt`, `llms-full.txt`, and Markdown versions of your pages.
It can also publish Agent Skills and an API catalog for your MCP server.

[Skew Protection](/docs/skew-protection/getting-started/introduction) keeps old build assets available after a deploy.
This prevents `ChunkLoadError` and missing chunks in open tabs and crawlers.
Under Nuxt SEO, it uses hourly app manifest polling, without a persistent connection or version cookie.

Both modules install by default. Keep their options under `aiReady` and `skewProtection`, or disable either:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxtjs/seo'],
  aiReady: false,
  skewProtection: false,
})
```

::warning
Cache `node_modules/.cache/nuxt-seo/skew-protection` between CI builds. Skew Protection needs those old assets after deployment.
::

## ⚡ Performance

In the full-module benchmark, including AI Ready, v6 improves on v5.3.16:

- **90% less server memory overhead.**
- **52% smaller compressed server builds.**
- **44% less browser JavaScript from Nuxt SEO.**

See the [benchmarks](https://github.com/harlan-zw/nuxt-seo/tree/main/bench/performance).

<details>
<summary>Benchmark results and what changed</summary>

The test app uses all nine modules, Nuxt i18n with two locales, and Satori.
“Over bare Nuxt” measures the added cost against the same app without Nuxt SEO.

| Metric | 5.3.12 | 5.3.16 | v6 |
|---|---|---|---|
| Nuxt SEO JavaScript in the browser, gzip | 22.6 KB | 26.8 KB | **14.9 KB** |
| Server build output, gzip | 12.5 MB | 8.7 MB | **4.2 MB** |
| Install size, over bare Nuxt | 108 MB | 125 MB | **73 MB** |
| Server memory after boot, over bare Nuxt | 146 MB | 148 MB | **14 MB** |
| Memory allocated per page render, over bare Nuxt | 1,031 KB | 954 KB | **921 KB** |

Schema.org's default mode and Robots' bot detection no longer send code to the browser.
Skew Protection's polling default saves 4.2 KB of the 11.9 KB reduction.
AI Ready now installs only your platform's Markdown converter binary ([#171](https://github.com/harlan-zw/nuxt-ai-ready/pull/171)).

Install size fell 42%. `drizzle-orm`, `zod`, `chrome-launcher`, `sharp`, and other-platform binaries are optional or removed.
Without the test app's Satori, resvg, and `better-sqlite3`, Nuxt SEO adds 15 MB. OG image renderers install separately.

The boot-memory reduction includes AI Ready's database code loading only when needed.
v5 projects without AI Ready did not pay that startup cost.

</details>

## 🖼️ OG Image v7

Satori 0.47 adds block, inline, and grid layout, plus `translate`, `rotate`, and `scale`.
Bare `<div>`{lang="html"} elements no longer get forced flex layout. Check custom templates before upgrading.

You can publish generated images to R2 or S3. Repeat requests skip rendering, and builds reuse images until their cache expires:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  ogImage: {
    publish: { storage: 'og-image-public', baseURL: 'https://images.example.com' },
  },
  nitro: {
    storage: {
      'og-image-public': { driver: 'cloudflare-r2-binding', binding: 'OG_IMAGES' },
    },
  },
})
```

Fonts use `@nuxt/fonts` v1. Prerendered images keep their fonts, and Takumi loads OTF and WOFF files.
See the [OG Image v7 migration guide](/docs/og-image/migration-guide/v7) for signing, layout, and renderer changes.

## ✅ Upgrading

v6 requires Nuxt `^4.6.1 || ^5.0.0` and Node `^22.22.3 || ^24.15.0 || >=26.0.0`.
If your project uses Nuxt 3, stay on Nuxt SEO v5.

Upgrade Nuxt first, then Nuxt SEO:

```bash
npx nuxt upgrade
npx nypm add @nuxtjs/seo@^6
```

Before deploying:

- If you use signed OG image URLs, set `NUXT_APP_SECRET` to at least 32 characters. Without it, production image requests return 500. Purge cached HTML containing OG Image v6 signed URLs.
- If you use the SEO DevTools panels, add `nuxtseo-devtools-host` as a development dependency.
- If you already installed AI Ready or Skew Protection, remove their separate entries from `modules` and dependencies.
- Update or remove older bundled-module pins. They now fail the build. Check [Module Versions](#module-versions).

The [migration guide](/docs/nuxt-seo/migration-guide/v5-to-v6) covers renderer, server hook, and Nuxt Content changes.
The full breaking-change reference is below.

- Cache node_modules/.cache/nuxt-seo/skew-protection in CI; Skew Protection stores assets there.
- Skew Protection v2: unset `updateStrategy` now means polling; `experimental.appManifest: false` throws.
- AI Ready v3: bots no longer get Markdown by User-Agent. Set `aiReady: { botNegotiation: true }` to keep it.

## 2. Pinned module versions
Minimums: @nuxtjs/robots 7, @nuxtjs/sitemap 9, nuxt-og-image 7, nuxt-schema-org 7,
nuxt-seo-utils 9, nuxt-link-checker 6, nuxt-site-config 5, nuxt-ai-ready 3,
nuxt-skew-protection 2, @nuxtjs/i18n 10. Update or remove older pins in package.json.

## 3. DevTools
If the project uses Nuxt DevTools, add `nuxtseo-devtools-host` as a dev dependency.

## 4. OG Image v7
- Search: `security.secret`, `NUXT_OG_IMAGE_SECRET`, `ogImage.secret`.
  Remove `security.secret`; set `NUXT_APP_SECRET` (32+ chars) in the deploy environment.
- Search: `*.satori.vue` and components in `components/OgImage/`.
  If an element relied on forced flex layout, add `flex flex-col` classes.
- Search: `fetchedResources`, `persistentImages`. Replace with `takumi.images`.
- Search: `"@takumi-rs/core"`, `"satori"`, `"@nuxt/fonts"`. Need ^2.15.0, ^0.47.1, >=1.0.0.
- Full guide: https://nuxtseo.com/docs/og-image/migration-guide/v7

## 5. Zod 4
Search: `defineRobotsSchema`, `defineSitemapSchema`, `defineOgImageSchema`, `"zod"`.
Upgrade zod to ^4; fix [Zod](https://zod.dev) 3 API usage in content.config.ts.

## 6. Server hooks and events
Search: `sitemap:`, `robots:` hook handlers, `event.node.req`, `H3Event`, `getOgImageUrl(`.
- Hook contexts now carry a `RequestEvent` from `nuxt/server`.
  Before: `ctx.event.node.req.headers.authorization`
  After:  `ctx.event.req.headers.get('authorization')`
- Handlers that call `getOgImageUrl` import `defineEventHandler` from `nuxt/server`.

## 7. Site Config v5
- Search: `updateSiteConfig(`. Without `_priority` it now ranks below the `site` key and env vars.
  If you need its old overrides, add `_priority: SiteConfigPriority.runtime`.
- Search: `indexable === undefined`, `indexable == null`. `indexable` is always a boolean now.
- Search: `installNuxtSiteConfig`. Replace with a `moduleDependencies` entry for nuxt-site-config.

## 8. Smaller changes
- `#internal/nuxt-robots`, `#internal/nuxt-simple-robots` -> `#robots/server` or `#robots/app`.
- Bare `#schema-org` -> `#schema-org/app`; bare `#seo-utils` -> `#seo-utils/app`.
- `nuxt-simple-robots`, `nuxt-simple-sitemap`: remove; use @nuxtjs/robots and @nuxtjs/sitemap.
- `@nuxt/content` v2: Nuxt SEO v6 no longer supports it. Upgrade to Content v3.6 or later.
- `nuxt-seo-utils icons`: add `sharp` as a dev dependency.
- `assets/robots.txt` or `pages/robots.txt` at the root: move under `srcDir` (`app/`).

## Verify

2. `npx nuxt typecheck`

## 🩺 Setup Checks in Development

After the first successful home page response, `nuxt dev` checks the installed modules for missing configuration.
Required checks report once per server start, with a fix and docs link.
Optional tips pause for seven days after showing. CI and AI agent sessions skip terminal output.

The checks also appear in DevTools, where you can refresh them. To hide tips while keeping required checks:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  nuxtseo: { tips: false },
})
```

## 🧩 DevTools on Demand

The SEO panels now use an optional host package. If you use them, install it:

```bash
npx nypm add -D nuxtseo-devtools-host
```

Panels show an install button when it is missing. Shared-core runtime dependencies dropped from 14 to 7.

## 🧭 More Module Improvements

- **Robots v7:** `blockAiBots: 'training'` blocks training crawlers while allowing AI search agents. Blocking Google-Extended also blocks [Gemini](https://gemini.google.com) grounding. Page rules now use your router's matching settings, aliases, and i18n routes.
- **Sitemap v9:** `definePageMeta({ sitemap: false })`{lang="ts"} excludes prerendered dynamic pages, aliases, and case or trailing-slash variants. Unused streaming and compression code leaves the build.
- **SEO Utils v9:** warns about indexable pages rendered only on the client. Derived meta tags take about half the CPU time per call.
- **Link Checker v6:** reports when no pages were scanned, shows actual HTTP status text, and retries `HEAD` responses of 405 or 501 with `GET`.
- **Site Config v5:** `getSiteConfig(event)`{lang="ts"} works in server middleware. Prerendering without `site.url` warns about relative URLs.
- **AI Ready v3:** Markdown negotiation uses only `Accept`. The AI Catalog also appears at `/.well-known/ard.json`.
- **Skew Protection v2:** tabs can share one connection through Web Locks. Core protection works without Robots or Site Config.

`nuxtseo: false` now skips bundled modules. Modules you add yourself still install.
Unsupported Nuxt versions and older pinned modules now stop the build with an error naming the version and fix.

## 🔌 Free MCP Server

The [Nuxt SEO MCP server](/docs/nuxt-seo/guides/mcp) provides docs and SEO checks without an account or API key.
The new `diagnose_url` tool returns a page score from 0 to 100, a grade, and findings with fixes, ordered by severity.
Other tools check meta tags, Schema.org, social cards, robots.txt, and sitemaps, or search docs and return install steps.

It is listed in Claude's Connectors Directory and the [MCP registry](https://registry.modelcontextprotocol.io) as `com.nuxtseo/nuxt-seo`.
To add it to Claude Code:

```bash
claude mcp add --transport http nuxt-seo https://nuxtseo.com/mcp
```

## ⚠️ Breaking Changes

Read the [migration guide](/docs/nuxt-seo/migration-guide/v5-to-v6) before deploying an upgrade.

<details>
<summary>Full breaking-change reference</summary>

### Nuxt 4.6.1 and Node 22.22.3 Minimum

Nuxt SEO v6 requires Nuxt `^4.6.1 || ^5.0.0`. Nuxt SEO v6 no longer supports Nuxt 3.

Node must match `^22.22.3 || ^24.15.0 || >=26.0.0`.

### AI Ready and Skew Protection Install by Default

Remove `nuxt-ai-ready` and `nuxt-skew-protection` from your `modules` array and your dependencies. `@nuxtjs/seo` installs them. Keep your options under `aiReady` and `skewProtection`, or set either key to `false`.

If you already configured Skew Protection, check these v2 changes:

- An unset `updateStrategy` now means hourly polling on every platform. For instant updates, set `updateStrategy: 'sse'` or `'ws'`.
- `experimental.appManifest: false` now fails setup.
- The default storage driver is `fs-lite`. An explicit `driver: 'fs'` still works.
- With `multiTab: true`, tabs share one push connection. To keep one connection per tab, set `multiTab: false` or `connectionTracking: true`.

If you already configured AI Ready, AI bots no longer get Markdown by User-Agent alone. Set `botNegotiation: true` to restore that. AI Ready drops the `better-sqlite3` fallback and uses `node:sqlite`.

### DevTools Panels Need `nuxtseo-devtools-host`

Install `nuxtseo-devtools-host` as a development dependency to keep the SEO panels. The DevTools on Demand section above shows the command.

### OG Image Signing Uses `NUXT_APP_SECRET`

If URL signing is on, set `NUXT_APP_SECRET` to a value of at least 32 characters. Without it, production OG image requests return a 500 error. Pages still render. If `security.secret` holds a string, remove it from your config. Generate a secret with `npx nuxt-og-image generate-secret`.

`NUXT_OG_IMAGE_SECRET` still works with a deprecation warning. Signed URLs from OG Image v6 become invalid, so purge cached HTML that contains them.

The [OG Image v7 migration guide](/docs/og-image/migration-guide/v7) also covers these changes:

- OG Image needs Satori 0.47. Add `flex flex-col` to elements that depended on the old forced flex layout.
- OG Image needs Takumi v2 (`^2.15.0`). Replace `takumi.fetchedResources` and `takumi.persistentImages` with `takumi.images`.
- Custom fonts need `@nuxt/fonts` v1. Families used only in OG images need `global: true`.

### Zod 4 for Nuxt Content Schemas

`defineRobotsSchema()`{lang="ts"}, `defineSitemapSchema()`{lang="ts"}, and `defineOgImageSchema()`{lang="ts"} require [Zod](https://zod.dev) 4. Upgrade the `zod` package in your app.

### Server Hooks Receive a `RequestEvent`

The `robots:*` and `sitemap:*` hook contexts now carry a `RequestEvent` from `nuxt/server`, in place of an h3 `H3Event`. Read request headers with the web API:

```ts [server/plugins/sitemap.ts]
export default defineNitroPlugin((nitroApp) => {
  nitroApp.hooks.hook('sitemap:sources', (ctx) => {
    // v5: ctx.event.node.req.headers.authorization
    const auth = ctx.event.req.headers.get('authorization')
  })
})
```

OG Image's `getOgImageUrl()`{lang="ts"} also takes a `RequestEvent`. Import `defineEventHandler` from `nuxt/server` in handlers that call it.

### Site Config Priority and Values

- `updateSiteConfig()`{lang="ts"} without `_priority` now ranks below your `site` key and `NUXT_SITE_*` variables. Pass `_priority: SiteConfigPriority.runtime` to keep the old order.
- `indexable` is now always a boolean. It defaults to `env === 'production'`.
- Module authors: Site Config v5 drops `installNuxtSiteConfig()`{lang="ts"}. Declare `nuxt-site-config` in `moduleDependencies`.

### Smaller Module Changes

- **Robots:** Robots v7 drops the `#internal/nuxt-robots` and `#internal/nuxt-simple-robots` aliases. Import from `#robots/server` or `#robots/app`. `robots.txt` files in `assets/` or `pages/` resolve from `srcDir` (`app/` in Nuxt 4).
- **Robots:** `noai` and `noimageai` route rules no longer mark a route as not indexable. A `robots:config` change made during a request now affects only that request.
- **Robots:** route rules now take precedence over `definePageMeta({ robots })`{lang="ts"}. If both set a rule for a page, the route rule wins.
- **Sitemap:** Sitemap v9 drops `nuxt-simple-robots` support. Use `@nuxtjs/robots` v7.
- **Link Checker:** Link Checker v6 drops Nuxt Content v2 support. Reports show the real status text, and an unreachable link reports status `0`.
- **SEO Utils:** `sharp` is an optional peer dependency. Add it to use `nuxt-seo-utils icons`. Runtime minification no longer rewrites inline JavaScript.
- **Schema.org and SEO Utils:** the bare `#schema-org` and `#seo-utils` aliases are replaced by `#schema-org/app`, `#schema-org/server`, and `#seo-utils/app`.
- **Nuxt Content:** Nuxt SEO v6 no longer supports Nuxt Content v2. Use Content v3.

</details>
