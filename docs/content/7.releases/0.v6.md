## Introduction

Nuxt SEO v6 adds AI Ready and Skew Protection to the bundle and updates all nine modules.
It requires Nuxt 4.6.1 or Nuxt 5. Nuxt 3 projects stay on v5.
For upgrade steps, see the [v5 to v6 migration guide](/docs/nuxt-seo/migration-guide/v5-to-v6).

::ui-button{to="/docs/nuxt-seo/migration-guide/v5-to-v6" purpose="secondary" size="sm"}
Skip to upgrade
::

## 🤖 AI Ready and Skew Protection, Bundled

[AI Ready](/docs/ai-ready/getting-started/introduction) generates `llms.txt`, `llms-full.txt`, and Markdown versions of your pages.
It can also publish Agent Skills and an API catalog for your MCP server.

[Skew Protection](/docs/skew-protection/getting-started/introduction) keeps old build assets available after a deploy.
This prevents `ChunkLoadError` and missing chunks in open tabs and crawlers.
Under Nuxt SEO, it uses hourly app manifest polling, without a persistent connection or version cookie.

Both modules install by default. See the [migration guide](/docs/nuxt-seo/migration-guide/v5-to-v6#step-2-update-nuxt-seo-remove-ai-ready-and-skew-protection-from-modules) for configuration.

## ⚡ Performance

In the full-module benchmark, including AI Ready, v6 improves on v5.3.16:

- **90% less server memory overhead.**
- **52% smaller compressed server builds.**
- **44% less browser JavaScript from Nuxt SEO.**

See the [benchmarks](https://github.com/harlan-zw/nuxt-seo/tree/main/bench/performance).

::details
<summary>Benchmark results and what changed</summary>

The test app uses all nine modules, Nuxt i18n with two locales, and Satori.
“Over bare Nuxt” measures the added cost against the same app without Nuxt SEO.

| Metric | 5.3.12 | 5.3.16 | v6 |
|---|---|---|---|
| Nuxt SEO JavaScript in the browser, gzip | 22.6 KB | 26.8 KB | **14.9 KB** |
| Server build output, gzip | 12.5 MB | 8.7 MB | **4.2 MB** |
| Install size, over bare Nuxt | 108 MB | 125 MB | **73 MB** |
| Server memory after boot, over bare Nuxt | 146 MB | 148 MB | **14 MB** |
| Memory allocated per page render, over bare Nuxt | 1,031 KB | 954 KB | **921 KB** |

Schema.org's default mode and Robots' bot detection no longer send code to the browser.
Skew Protection's polling default saves 4.2 KB of the 11.9 KB reduction.
AI Ready now installs only your platform's Markdown converter binary ([#171](https://github.com/harlan-zw/nuxt-ai-ready/pull/171)).

Install size fell 42%. `drizzle-orm`, `zod`, `chrome-launcher`, `sharp`, and other-platform binaries are optional or removed.
Without the test app's Satori, resvg, and `better-sqlite3`, Nuxt SEO adds 15 MB. OG image renderers install separately.

The boot-memory reduction includes AI Ready's database code loading only when needed.
v5 projects without AI Ready did not pay that startup cost.

::

## 🖼️ OG Image v7

Satori 0.47 adds block, inline, and grid layout, plus `translate`, `rotate`, and `scale`.

You can publish generated images to R2 or S3. Repeat requests skip rendering, and builds reuse images until their cache expires:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  ogImage: {
    publish: { storage: 'og-image-public', baseURL: 'https://images.example.com' },
  },
  nitro: {
    storage: {
      'og-image-public': { driver: 'cloudflare-r2-binding', binding: 'OG_IMAGES' },
    },
  },
})
```

Fonts use `@nuxt/fonts` v1. Prerendered images keep their fonts, and Takumi loads OTF and WOFF files.
See the [OG Image v7 migration guide](/docs/og-image/migration-guide/v7) for signing, layout, and renderer changes.

## 🩺 Setup Checks in Development

After the first successful home page response, `nuxt dev` checks the installed modules for missing configuration.
Required checks report once per server start, with a fix and docs link.
Optional tips pause for seven days after showing. CI and AI agent sessions skip terminal output.

The checks also appear in DevTools, where you can refresh them. To hide tips while keeping required checks:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  nuxtseo: { tips: false },
})
```

## 🧩 DevTools on Demand

The SEO panels now use an [optional host package](/docs/nuxt-seo/migration-guide/v5-to-v6#step-2-update-nuxt-seo-install-the-devtools-host).
Panels show an install button when it is missing. Shared-core runtime dependencies dropped from 14 to 7.

## 🧭 More Module Improvements

- **Robots v7:** `blockAiBots: 'training'` blocks training crawlers while allowing AI search agents. Blocking Google-Extended also blocks [Gemini](https://gemini.google.com) grounding. Page rules now use your router's matching settings, aliases, and i18n routes.
- **Sitemap v9:** `definePageMeta({ sitemap: false })`{lang="ts"} excludes prerendered dynamic pages, aliases, and case or trailing-slash variants. Unused streaming and compression code leaves the build.
- **SEO Utils v9:** warns about indexable pages rendered only on the client. Derived meta tags take about half the CPU time per call.
- **Link Checker v6:** reports when no pages were scanned, shows actual HTTP status text, and retries `HEAD` responses of 405 or 501 with `GET`.
- **Site Config v5:** `getSiteConfig(event)`{lang="ts"} works in server middleware. Prerendering without `site.url` warns about relative URLs.
- **AI Ready v3:** Markdown negotiation uses only `Accept`. The AI Catalog also appears at `/.well-known/ard.json`.
- **Skew Protection v2:** tabs can share one connection through Web Locks. Core protection works without Robots or Site Config.

`nuxtseo: false` now skips bundled modules. Modules you add yourself still install.
Unsupported Nuxt versions and older pinned modules now stop the build with an error naming the version and fix.

## 🧠 Agent Skill in the Package

Every module ships an Agent Skill. The [Nuxt SEO Skill](https://skilld.dev/gh/harlan-zw/nuxt-seo/nuxtjs-seo) covers config ownership, disabling modules, and install errors.
It ships at `skills/nuxtjs-seo/SKILL.md`.

## 🔌 Free MCP Server

The [Nuxt SEO MCP server](/docs/nuxt-seo/guides/mcp) provides docs and SEO checks without an account or API key.
The new `diagnose_url` tool returns a page score from 0 to 100, a grade, and findings with fixes, ordered by severity.
Other tools check meta tags, Schema.org, social cards, robots.txt, and sitemaps, or search docs and return install steps.

It is listed in Claude's Connectors Directory and the [MCP registry](https://registry.modelcontextprotocol.io) as `com.nuxtseo/nuxt-seo`.
To add it to Claude Code:

```bash
claude mcp add --transport http nuxt-seo https://nuxtseo.com/mcp
```
