## Install Nuxt SEO Alias

The `@nuxtjs/seo` module installs all nine Nuxt SEO modules in one step.

:ModuleInstall{name="@nuxtjs/seo"}

`@nuxtjs/seo` v6 needs Nuxt 4.6.1 or later, and Node `^22.22.3 || ^24.15.0 || >=26.0.0`. On an earlier Nuxt version, the build stops with an error that names your version and the required range. To upgrade Nuxt, run `npx nuxt upgrade`. If your site runs Nuxt 3, stay on Nuxt SEO v5.

If you pin a bundled module yourself, it must satisfy the version that `@nuxtjs/seo` requires. If it does not, the build fails and names the module.

## Which package should I install?

Use `@nuxtjs/seo` for new projects when you want the standard SEO stack: Sitemap, Robots, OG Image, Schema.org, Link Checker, SEO Utils, Site Config, AI Ready, and Skew Protection.

Install individual modules only when you want a smaller dependency set or need to pin module versions yourself.

::tip{icon="i-heroicons-arrow-path"}
Upgrading an existing project? Check the [Updating Modules](/docs/nuxt-seo/guides/updating-modules) guide first, then follow the relevant [migration guide](/docs/nuxt-seo/migration-guide/v5-to-v6) if you are crossing a major version.
::

### Install Modules Individually

If you only need specific modules or want version pinning control, install them separately. Each module works independently and you can mix and match as needed.

::note{icon="i-heroicons-information-circle"}
`nuxt-site-config` installs automatically with any SEO module. You do not need to add it manually.
::

:AllModules

### AI Ready and Skew Protection

`@nuxtjs/seo` installs [AI Ready](/docs/ai-ready/getting-started/introduction) and [Skew Protection](/docs/skew-protection/getting-started/introduction) with the other modules. Do not add `nuxt-ai-ready` or `nuxt-skew-protection` to `modules` again.

To turn either module off, set `aiReady: false`{lang="ts"} or `skewProtection: false`{lang="ts"}. The [Using the Modules](/docs/nuxt-seo/guides/using-the-modules#ai-ready) guide lists their defaults.
